03 / Computer vision

Vision-based
Ping Pong

A familiar game. A different kind of controller.

  • Python
  • OpenCV
  • Real-time interaction

Why it exists

An arcade experiment exploring how hand gestures can replace physical controls.

Let's talk about this build
↗

What I built

Real-time hand capture and tracking with OpenCV, translated into paddle movement using smoothing algorithms.

Under the surface The engineering behind the experience

Technical challenge

Turning noisy gesture detection into smooth, responsive paddle control without losing the immediacy of play.

Prototype outcome

A gesture-controlled arcade game that can be played without a physical controller.
